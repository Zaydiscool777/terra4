i like what happened for this week. i added two menus to the game now:
a level menu and a main menu. the main menu pops up when you start up the game,
and you return to it when you finish the last level. there is a button on the main menu to
start the game on the first level.
the level menu is where you can access all the levels.
you can access the level menu with q, and there is a button for each level
with the level number as the label.
each level also has a strat position, so now you can start
where the portal of the last level was in the next level.

How to run: it's an elf executable, so on linux:
- go to [releases](https://github.com/Zaydiscool777/terra4/releases/tag/release1.1)
- download file (https://github.com/Zaydiscool777/terra4/releases/download/release1.1/isol.zip)
- decompress using `unzip`
- `chmod +x` the executable
- `./[file]` the executable
- Esc or close button to close
note: that is a dash not a dot
